# Янис Салимов — английский для международной карьеры

Адаптивный лендинг на русском: HTML, CSS и небольшой JavaScript для мобильного меню. Не требует установки пакетов или сборки. Все основные кнопки ведут в Telegram или в анкету курса; сайт не собирает персональные данные и не имитирует отправку заявки.

## Vercel

Импортируйте `rimmasalimova/siteforyanis` в Vercel. Ветка Production — `main`, корневая папка — корень репозитория, Framework Preset — `Other`. Сборка не нужна; настройки статического сайта находятся в `vercel.json`. Если проект уже подключён с этими настройками, новый коммит в `main` запускает автоматическую публикацию.

## Локальный просмотр

Откройте `index.html` в браузере либо запустите `python -m http.server 4173` из папки сайта.

## Файлы

- `index.html` — содержание и ссылки.
- `styles.css` — оформление и адаптация к размеру экрана.
- `script.js` — доступное мобильное меню.
- `assets/yanis.webp` — предоставленная владельцем фотография, оптимизированная для сайта.

В разделе отзывов — шесть предоставленных владельцем изображений переписки. Каждая карточка открывает увеличенное изображение; можно закрыть его кнопкой или клавишей Escape.
